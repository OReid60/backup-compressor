Release summary from v2.2.0:
Backup Compressor v2.2.0 is a Windows backup utility release focused on SQL Server backup support, Google Drive cloud integration, scheduler improvements, startup behavior, UI cleanup, and stability fixes.

New features in v2.2.0:
- Added SQL Server connection testing.
- Added manual SQL Server .bak backup creation.
- Added scheduled SQL backups.
- Added support for backing up multiple databases from one SQL Server instance.
- Added a Load Databases discovery button.
- Added Google OAuth authentication.
- Added Google Drive connection controls.
- Added Google Drive disconnection controls.
- Added Google Drive upload test functionality.
- Added secure token.json account persistence.
- Added schedule names.
- Added schedule descriptions.
- Added weekday assignment for each schedule.
- Added richer scheduler list entries showing name, time, description, and days.
- Added immediate save behavior after adding a scheduled time.
- Added permanent delete behavior after removing a selected schedule.
- Replaced startup buttons with a checkbox for starting Backup Compressor with Windows.

UI improvements in v2.2.0:
- Expanded the scheduler listbox.
- Improved scheduler button alignment.
- Improved Settings tab organization.
- Clarified the workflow:
  Backup: one-time local backup
  Scheduler: automated local scheduling
  Settings: SQL and cloud automation

Fixes in v2.2.0:
- Fixed removed schedules reappearing after restart.
- Fixed added schedules not refreshing immediately.
- Fixed startup checkbox not appearing.
- Fixed scheduler row overlap.
- Fixed SQL SSL certificate issue by using sqlcmd -C.
- Fixed the disconnect button not showing.

Core app features listed on the release:
- Backup multiple files and folders.
- Supports ZIP, 7Z, and RAR archive formats.
- Built-in backup scheduler.
- System tray integration for background operation.
- Progress tracking and logs.
- Backup profile saving and loading.
- Fast, lightweight Windows utility.

Additional improvements listed on the release:
- Improved tray icon using a clean circular design.
- Added AppData storage for settings and logs.
- Scheduler status is reflected in the tray icon.
- Backup completion notifications.
- UI layout cleanup.
- Stability and performance improvements.

Requirements:
- Windows 10 or Windows 11.
- WinRAR is required only for RAR backups.
- 7-Zip is required only where 7Z support is needed.

Notes:
- Backup logs and settings are stored in:
  AppData\Roaming\Multi Backup Compressor
- Existing settings are preserved during upgrades.
- Always verify backups before deleting original files.
